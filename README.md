# 批量编辑与开关方案助手（st-bulk-scheme-helper）

一个 SillyTavern（酒馆）扩展，给 **预设条目** 和 **世界书条目** 加上批量编辑和「开关方案」，并提供一个所有预设共用的「记录表」：把自己写的、改过的条目存起来，放进别的预设，或者在作者发布新版本时连同开关状态一起搬过去。

主要针对手机（iPhone）触屏操作做了适配，电脑端也能用。

---

## 安装

1. 打开 SillyTavern →「扩展」面板 →「安装扩展」
2. 粘贴本仓库地址：

   ```
   https://github.com/Nuyoah-Rena/st-bulk-scheme-helper
   ```

3. 安装完成后刷新页面。打开预设列表或世界书，列表上方出现方案栏，就说明加载成功了。

### 版本要求

- 预设相关功能针对 **Chat Completion** 预设
- **SillyTavern 1.13.2 及以上**：预设开关方案会存进预设文件，随预设导出、导入、改名
- 低于 1.13.2 也能用，但预设方案只存在扩展设置里，不会跟着预设导出
- 作者日常使用的版本：SillyTavern 1.19.1

### 可选搭配：ST-BaiBai-Tools

以下功能需要同时安装 ST-BaiBai-Tools 并开启它的预设分组，没装也不影响其他功能：

- 开关方案记录 / 恢复 **分组供电** 状态
- 条目「⋯」菜单里的 ➕ 插入按钮
- 屏幕右侧的「折叠当前分组」按钮
- 插入条目时自动进入目标条目所在的分组

## 功能一览

### 1. 顶部方案栏

预设列表和世界书列表上方各有一条：

| 按钮 | 作用 |
| --- | --- |
| 方案：xxx ▾ | 打开「切换开关方案」窗口 |
| 🔖 | 把当前所有条目的开 / 关状态存为方案 |
| 📦 | 打开记录表（仅预设） |
| 批量编辑 | 进入 / 退出批量编辑模式 |

**长按方案栏** 会弹出菜单：

- **编辑卡片**：拖动改位置，拖右下角改大小，点 ✔ 确认、✖ 取消
- **字体大小**：10–18px，每档 0.5px
- **恢复默认位置**：清除位置和大小（字号保留）。只有改过位置时才会出现

### 2. 批量编辑

进入批量编辑后，每个条目前会出现勾选框，屏幕左侧出现悬浮条：

| 按钮 | 作用 |
| --- | --- |
| 全选 / 清空 | 圆钮上显示已选数量 |
| 开 / 关 | 批量开启或关闭已选条目 |
| ↕ 区间连选 | 勾选首尾两条，中间自动全选 |
| 🔖 | 存为方案 |
| 📦 存底 | 把已选条目存进记录表（仅预设） |
| 导出 | 已选条目导出为 JSON |
| 🗑 删除 | 删除前会确认。SillyTavern 的 12 个内置条目（主提示词、聊天记录、世界书、角色描述等）会被跳过，不会删除 |
| ‹ | 收起成小球，点小球展开 |
| ✕ | 退出批量编辑 |

**只对看得见的条目生效**：被 BaiBai 搜索过滤掉的条目、收起的分组里的条目，会自动取消勾选，不会被误开、误关或误删。

### 3. 开关方案

方案记录的是「哪些条目开、哪些条目关」，可以一键切换。

- **预设方案存在预设文件里**，导出 / 导入预设时会跟着走（需要 SillyTavern 1.13.2+）
- 世界书方案按世界书分别保存
- 方案列表支持：按住 ☰ 拖动排序、重命名、用当前开关覆盖、删除
- 点方案名查看详情：上下分栏显示「已开启 / 已关闭」，中间的分割条可以拖动，标题旁的小按钮可以只展开一栏
- **变动提醒**：预设条目新增、修改内容或删除后，对应的方案旁会出现绿点；详情里用绿色标出「新增 / 已改 / 已删」，点「同步变动」即可更新方案（新增条目记为关闭）
- **刷新全部方案**（仅预设）：一次性给当前预设的所有方案同步条目变动

### 4. 方案绑定聊天窗口

在方案列表里点 🔗：

1. 选择角色卡（显示头像，可以搜索）
2. 勾选这张角色卡下的聊天窗口

之后打开这个聊天窗口时，会自动切换到绑定的方案。

- 预设方案只在「当前选中的预设」和绑定时的预设一致时才会自动应用
- 可以在弹窗顶部一键「绑定当前」聊天
- 群聊不支持绑定

### 5. 记录表（仅预设）

记录表 **所有预设共用**，用来保存自己写的、改过的条目，之后可以放进任何一个预设。条目从哪个预设来都无所谓，原来的预设删掉也不影响。

记录的来源有两种：

- **存底·手动**：在批量编辑里勾选条目，点悬浮条上的 📦。同名记录会被新的覆盖
- **新增·自动**：安装本扩展后再导入的预设，会记下作者原有的条目；之后你新加的条目（手动新建、复制、用其他插件缝合进来的）会自动进入记录表，不会覆盖手动存底的同名记录

每条记录会保存：条目完整内容、存底时的开关状态、它原本的上一条 / 下一条邻居、所在分组。

在记录表里可以：

- 搜索名字或内容（不区分大小写），命中处显示黄色高亮，👁 可以关闭高亮
- 单选、全选 / 清空、区间选择；点「已选 N 条」可以查看并剔除已选
- 按住 ☰ 拖动排序
- 查看完整内容，以及它原本的上一条 / 下一条邻居
- 删除记录（不影响预设里的条目）
- **记录方案**：把一组记录存个名字，点开后可以单选、区间选、全选，还可以添加、移出、重命名
- **导出 / 导入**：JSON 文件，包含排序和记录方案；只选了部分记录时只导出已选的

> ⚠️ 记录表存在 SillyTavern 的扩展设置里，**不会跟着预设导出**。重装酒馆或换设备前，记得先在记录表里点「导出」备份。

### 6. 把记录放回预设

有三种方式，**都不会自动保存预设**。完成后会弹出报告，列出每一条放到了哪里、哪些没放进来以及原因，方便截图核对。检查无误后再点 SillyTavern 的「保存预设」；如果不满意，切换一次预设就能放弃这次改动。

**➕ 插入**（需要 BaiBai）
在条目的「⋯」菜单里点 ➕，选好记录，插到这一条下面。当前预设里已经有的记录显示为灰色、不能选。

**放进当前预设**
在记录表里选好记录后点击（必须先选，不会默认全选）：

- 当前预设里有同名条目 → 在它下面插一份名字带 🌈 的副本；如果记录是开着的，原条目会被关掉
- 没有同名条目 → 按记录里保存的上下邻居自动找位置；几条连在一起的记录，只要有一条找到位置，其余的会按原顺序跟着放
- 都找不到 → 在报告里列出，可以用 ➕ 手动插入

**版本升级融合**
适合作者发布新版本预设后使用。先导入新版并设为当前预设，再选择旧版本（名字只差版本号的会标「推荐」），会把以下内容从旧版搬过来：

- 条目开关（新旧条目依次按 ID、名字、内容匹配；作者新加的条目默认关闭）
- 开关方案
- 正则脚本的启用 / 停用状态
- BaiBai 分组供电
- 旧版里包含的记录（规则同「放进当前预设」，融合前会先用旧版里的最新内容更新这些记录）

报告里还会列出「你在旧版开着、但新版找不到」的作者条目，方便你自己找替代。

重复融合不会重复插入：已经融合过的记录会被跳过，开关状态也不会被改动。

> 融合读取的是旧版预设 **最后一次保存** 时的状态。融合前请确认旧版里的修改都已经点过「保存预设」。
>
> 融合完成、检查无误并保存后，旧版本就可以删除了（建议先导出备份）。下次作者更新时，从这一版融合即可。

### 7. 折叠当前分组（需要 BaiBai）

打开预设列表且屏幕上有展开的分组时，右侧会出现一个圆钮。点一下，就会折叠屏幕中间那个分组，并把它的标题留在屏幕上，不用再往上滑去找折叠按钮。

## 数据存放位置

| 内容 | 位置 |
| --- | --- |
| 预设开关方案 | 预设文件 `extensions.stBulkSchemeHelper.schemes`（扩展设置里也留一份） |
| 预设的导入记录（新增·自动用） | 预设文件 `extensions.stBulkSchemeHelper` |
| 世界书开关方案 | 扩展设置 `st_bulk_scheme_helper` |
| 聊天窗口绑定 | 扩展设置 |
| 记录表、记录方案 | 扩展设置 |
| 方案栏位置 / 字号 | 扩展设置 |

---

## 说明

- 世界书的批量操作和方案切换会直接写入世界书文件
- 预设的条目开关、插入的条目和融合结果需要点「保存预设」才会写入预设文件；开关方案本身会自动存进预设文件
