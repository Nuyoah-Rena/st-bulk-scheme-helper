# 批量编辑与开关方案助手（st-bulk-scheme-helper）

一个 SillyTavern（酒馆）扩展，给 **预设条目** 和 **世界书条目** 加上批量编辑和「开关方案」，并提供一个跨预设共用的「记录表」，方便在预设版本升级时把自己加的条目和开关状态搬过去。

针对手机（iPhone）触屏操作做过适配，电脑端也能用。

---

## 安装

1. 打开 SillyTavern →「扩展」面板 →「安装扩展」
2. 粘贴本仓库地址：

   ```
   https://github.com/<你的GitHub用户名>/st-bulk-scheme-helper
   ```

3. 安装完成后刷新页面。打开预设列表或世界书，列表上方出现方案栏即表示加载成功。

### 可选搭配：ST-BaiBai-Tools

以下功能需要同时安装 ST-BaiBai-Tools 的预设分组功能，没装也不影响其他功能：

- 开关方案记录 / 恢复 **分组供电** 状态
- 条目「⋯」菜单里的 ➕ 插入按钮
- 屏幕右侧的「折叠当前分组」按钮
- 插入条目时自动跟随目标条目所在分组

## 功能一览

### 1. 顶部方案栏

预设列表和世界书列表上方各有一条：

| 按钮 | 作用 |
| --- | --- |
| 方案：xxx ▾ | 打开「切换开关方案」窗口 |
| 🔖 | 把当前所有条目的开/关状态存为方案 |
| 📦 | 打开记录表（仅预设） |
| 批量编辑 | 进入 / 退出批量编辑模式 |

**长按方案栏** 弹出菜单：

- **编辑卡片**：拖动改位置，拖右下角改大小，点 ✔ 确认、✖ 取消
- **字体大小**：10–18px 调节
- **恢复默认位置**：清除位置和大小（保留字号）

### 2. 批量编辑

进入批量编辑后，每个条目前出现勾选框，屏幕左侧出现悬浮条：

- **全选 / 清空**（圆钮上显示已选数量）
- **开 / 关**：批量开启或关闭已选条目
- **↕ 区间连选**：勾选首尾两条，中间自动全选
- **🔖 存为方案**
- **📦 存底**：把已选条目存进记录表（仅预设）
- **导出**：已选条目导出为 JSON
- **🗑 删除**：删除前会确认；SillyTavern 内置条目（主提示词、聊天记录、角色描述等）会被跳过，不会删除
- **‹ 收起成小球** / **✕ 退出**

配合 BaiBai 的预设搜索使用时，只会对当前搜索结果里可见的条目生效。

### 3. 开关方案

方案记录的是「哪些条目开、哪些条目关」，一键切换。

- **预设方案存在预设文件里**，导出 / 导入预设时会跟着走
- 世界书方案按世界书分别保存
- 方案列表支持：按住 ☰ 拖动排序、重命名、用当前开关覆盖、删除
- 点方案名查看详情：上下分栏显示「已开启 / 已关闭」，中间分割条可拖动，标题旁小按钮可单栏展开
- **变动提醒**：预设条目新增、内容修改、删除后，对应方案会出现绿点，详情里用绿色标出「新增 / 已改 / 已删」，可点「同步变动」更新方案（新增条目记为关闭）
- **刷新全部方案**（预设）：一次性给当前预设的所有方案同步条目变动

### 4. 方案绑定聊天窗口

在方案列表里点 🔗：

1. 选角色卡（带头像，可搜索）
2. 勾选该角色卡下的聊天窗口

之后打开这个聊天窗口时，会自动切换到绑定的方案。

- 预设方案只在当前选中的预设与绑定时一致时才会自动应用
- 也可以在弹窗顶部一键「绑定当前」聊天
- 群聊不支持绑定

### 5. 记录表（仅预设）

记录表 **所有预设共用**，用来保存自己写的 / 改过的条目，以便放进别的预设或新版本预设。

记录来源有两种：

- **存底·手动**：批量编辑里勾选条目，点悬浮条上的 📦
- **新增·自动**：安装本扩展后导入的预设，会记下作者原有的条目；之后你新加的条目会自动进入记录表（不会覆盖手动存底的同名记录）

记录表里可以：

- 搜索名字或内容，命中处黄色高亮（👁 可关闭高亮）
- 单选、全选、区间选择，查看已选列表
- 按住 ☰ 拖动排序
- 查看完整内容，以及它原本的上一条 / 下一条邻居
- 删除记录（不影响预设里的条目）
- **记录方案**：把一组记录存个名字，之后可以一次选中
- **导出 / 导入**：JSON 文件，包含排序和记录方案

> ⚠️ 记录表存在 SillyTavern 的扩展设置里。重装酒馆或换设备前，记得先导出备份。

### 6. 把记录放回预设

三种方式，**都不会自动保存预设**。完成后会弹出报告，检查无误再点 SillyTavern 的「保存预设」；如果不满意，切换一次预设即可放弃改动。

**➕ 插入**（需要 BaiBai）
在条目的「⋯」菜单里点 ➕，选记录，插到这条下面。当前预设里已有的记录显示为灰色。

**放进当前预设**
在记录表里选好记录后点击：

- 当前预设里有同名条目 → 在它下面插一份带 🌈 的副本（如果记录是开着的，原条目会关掉）
- 没有同名条目 → 按记录里保存的上下邻居自动找位置
- 都找不到 → 在报告里列出，可以用 ➕ 手动插入

**版本升级融合**
适合作者发布新版预设后使用。先把新版设为当前预设，再选择旧版本（名字相近的会标「推荐」），会把以下内容从旧版搬过来：

- 条目开关（新旧条目按 ID → 名字 → 内容依次匹配；作者新加的条目默认关闭）
- 开关方案
- 正则脚本的启用 / 停用状态
- BaiBai 分组供电
- 记录表里的条目（规则同「放进当前预设」）

报告里还会列出「你在旧版开着、但新版找不到」的作者条目，方便自己找替代。

### 7. 折叠当前分组（需要 BaiBai）

打开预设列表且有展开的分组时，屏幕右侧出现一个圆钮，点一下折叠屏幕中间那个分组。

## 数据存放位置

| 内容 | 位置 |
| --- | --- |
| 预设开关方案 | 预设文件 `extensions.stBulkSchemeHelper.schemes`（同时在扩展设置里留一份） |
| 世界书开关方案 | 扩展设置 `st_bulk_scheme_helper` |
| 聊天窗口绑定 | 扩展设置 |
| 记录表、记录方案 | 扩展设置 |
| 方案栏位置 / 字号 | 扩展设置 |

较旧版本的 SillyTavern 如果没有预设扩展字段接口，预设方案只会存在扩展设置里，不会随预设导出。

- 世界书的批量操作和方案切换会直接写入世界书文件
