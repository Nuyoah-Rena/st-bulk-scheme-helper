# 批量编辑与开关方案助手

SillyTavern（酒馆）扩展。给**预设条目**和**世界书条目**加上批量编辑和「开关方案」：勾选多条一起开关，把一整套开关状态存起来随时切换。预设还多一个「记录表」，换新版预设时可以把自己加的条目和开关搬过去。

按手机（iPhone）操作设计，电脑也能用。

## 功能一览

- **批量编辑**：勾选条目后批量开/关、导出、删除，支持区间连选
- **开关方案**：保存当前所有条目的开/关状态，一键切换（预设、世界书都能用）
- **记录表**（仅预设）：存下自己加的条目，换预设或换版本时放回去
- **版本升级融合**（仅预设）：把旧版预设的开关、方案、正则启用状态、分组供电搬到新版
- **配合 ST-BaiBai-Tools**（可选）：分组供电记进方案、➕ 从记录表插入、一键折叠当前分组

## 安装

1. 打开酒馆，点顶部 🧩「扩展」
2. 点「安装扩展」
3. 粘贴本仓库地址：`[https://github.com/你的用户名/仓库名](https://github.com/Nuyoah-Rena/st-bulk-scheme-helper)`
4. 点「安装」，装好后刷新页面

装好后打开预设面板的提示词列表，或者打开世界书，列表上方会多出一条工具栏。

**更新**：扩展 → 管理扩展 → 找到本扩展，点更新。

| 批量编辑 | 进入 / 退出批量模式 |

## 批量编辑

点「批量编辑」后，每个条目前面出现勾选框，屏幕左边出现竖着的悬浮条：

| 按钮 | 作用 |
|---|---|
| 数字（全选） | 显示已选数量；点一下全选，再点清空 |
| 开 / 关 | 把勾选的条目全部打开 / 关闭 |
| ↕ | 区间连选（见下） |
| 🔖 | 存为方案 |
| 📦 | 存底到记录表（仅预设） |
| 导出 | 把勾选条目导出为 JSON 文件 |
| 🗑 | 删除勾选条目（会再确认一次，**删了不能恢复**） |
| ‹ | 收起成小球，点小球再展开 |
| ✕ | 退出批量编辑 |

**区间连选**有两种用法：

- 先勾第一条和最后一条，再点 ↕，中间全部选上
- 先点 ↕，再依次勾第一条和最后一条

预设里酒馆自带的系统条目（主提示词、聊天记录、角色描述等）受保护，不会被删掉。

## 开关方案

记下当前**所有条目**的开/关状态，起个名字（比如「港风」「双语」），以后一键切回来。每个预设、每本世界书都有各自的方案。

**保存**：点 🔖，输入名字后确认。点输入框下面已有的方案名可以直接填进去，同名会覆盖。

**切换**：点「方案：xxx ▾」打开方案列表：

- 点方案名 → 看详情：分成「已开启」和「已关闭」两栏，中间的横条可以上下拖动调整比例，栏右侧的小按钮能把这一栏放大到整个窗口。确认后点「应用此方案」
- ✏️ 重命名　💾 用当前开关覆盖这个方案　🗑 删除
- 按住左边的 ☰ 可以拖动排序

**方案过期提醒**（预设）：作者更新了条目、或者你自己改过之后，方案名旁边会出现一个绿点。详情里绿色的条目会标「新增 / 已改 / 已删」，点「同步变动」就能更新这个方案（新增的条目记为关闭）。列表顶部的「刷新全部方案」可以一次同步所有方案。

**方案跟着预设走**：预设的开关方案保存在预设文件里，导出或分享预设时会一起带走（需要较新版本的酒馆，旧版本只存在本地）。世界书的方案存在本地酒馆设置里。

装了 BaiBai 分组的话，方案还会记下每个分组的供电开关，应用方案时一起切换。

## 记录表（仅预设）

用来放**你自己加进预设的条目**。所有预设共用一张表，换预设、换版本都能拿出来用。

**条目怎么进来：**

- **存底·手动**：在批量编辑里勾选条目，点悬浮条上的 📦
- **新增·自动**：装好本扩展之后**导入**的预设，你在里面新加的条目会自动记进来（作者原有的条目不会记）

同名记录会覆盖旧的。

**记录表里能做的事：**

- 点卡片选中；可以全选、↕ 区间选、🔍 查找名字或内容（👁 按钮控制高亮开关）
- ⤢ 查看完整内容，以及它原来上下挨着的是哪两条
- 按住 ☰ 拖动排序
- 层叠图标 = **记录方案**：把一组记录存个名字，下次一点就选好了
- 🗑 删除已选记录（只删记录，不影响预设）
- 导出 / 导入：备份或分享记录表

> ⚠️ 记录表存在本地酒馆设置里，**不在预设文件里**。重装酒馆之前记得先导出。

### 放进当前预设

选好记录，点「放进当前预设」：

- 当前预设里**有同名条目**：在它下面插一份「名字 🌈」副本；如果你的记录是开着的，原条目会被关掉
- **没有同名的**：按它原来的上下邻居自动找位置
- 找不到位置的会在结果里列出来，可以用 ➕ 手动插入
- 已经在当前预设里的会跳过

### 版本升级融合

作者出了新版预设时：先导入新版并切换过去，再打开记录表点「版本升级融合」，选择旧版本（同一个预设的旧版本会标「推荐」）。会搬过来的内容：

- 每个条目的开关（对得上的保持原样，作者新加的一律关闭）
- 开关方案
- 正则的启用 / 停用状态
- BaiBai 分组供电
- 记录表里的条目（没选记录时，默认融合旧版里包含的那些）

结果页会列出放进来的、没放进来的，还有「你开着、但新版里找不到」的作者条目（作者可能删了或改名了，需要你自己找替代）。

> ⚠️ 「放进当前预设」和「版本升级融合」都**不会自动保存**。检查没问题后，点酒馆的「保存预设」。不满意的话切换一次预设，这次的改动就放弃了。

### ➕ 从记录表插入（需要 BaiBai）

条目的「⋯」菜单里（收藏按钮左边）会多一个 ➕，点开可以从记录表选条目，插到这一条下面。灰色的表示当前预设里已经有了。插入后同样要点「保存预设」。

## 配合 ST-BaiBai-Tools

不装 BaiBai 也能正常用。装了之后会多出这些：

- 开关方案会记录分组供电
- 条目「⋯」菜单里的 ➕ 插入，插入的条目会进入目标条目所在的分组
- 屏幕右边出现一个圆形按钮，一键折叠当前展开的分组

---

## 常见问题

**工具栏没出现？**
确认扩展已启用，然后刷新页面。预设的工具栏只出现在「聊天补全（Chat Completion）」的提示词列表上方。

**批量编辑世界书时提示「请先选择一本世界书」？**
先在世界书顶部的下拉框里选一本。

**删除的条目能找回吗？**
不能，删除前请确认。
